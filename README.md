Корпоративная сетевая топология уровня L2/L3 (Router-on-a-Stick)

Учебный проект по проектированию и настройке сетевой инфраструктуры в **Cisco Packet Tracer**. Проект демонстрирует практические навыки сегментации сети, маршрутизации и автоматизации выдачи IP-адресов.

---

## Стек технологий и функционал
* **Сетевые уровни:** L2 / L3 (Модель OSI)
* **VLAN (Виртуальные локальные сети):** Сегментация трафика под различные отделы/пользователей для изоляции и безопасности.
* **Trunking (Транковые порты):** Настройка транковых соединений для передачи трафика нескольких VLAN через один физический линк.
* **Router-on-a-Stick (ROAS):** Организация межсетевой маршрутизации (Inter-VLAN routing) через один физический интерфейс маршрутизатора с использованием подинтерфейсов (subinterfaces).
* **DHCP-сервер:** Настройка динамической выдачи IP-адресов, шлюзов и DNS для клиентов в каждом VLAN.
* **IP-адресация:** Продуманная схема распределения подсетей.

Как открыть проект?
1. Установите симулятор **Cisco Packet Tracer** рекомендуется версия 8.x и выше.
2. Скачайте файл проекта `*.pkt` из этого репозитория.
3. Откройте файл в программе для тестирования пингов, проверки таблиц маршрутизации `show ip route` и работы DHCP.
